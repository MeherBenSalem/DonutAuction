# DonutAuctionHouse v1.5.1

### Improvements
* Store tags extended to Minecraft **26.3**.

### Compatibility
* Paper and Folia, Minecraft 1.20.1 through 26.3, Java 17.
* Legacy support for 1.20.1–26.2 is unchanged.

### Upgrade Notes
1. Replace the jar. Keep existing `plugins/DonutAuctionHouse/` data.
2. Restart the server.
